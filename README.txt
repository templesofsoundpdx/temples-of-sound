To preview locally:
Open index.html in a browser.

To publish on GitHub Pages:
1. Create a GitHub repository, for example temples-of-sound.
2. Upload every file in this folder to the root of the repository.
3. Repository Settings > Pages > Deploy from branch > main / root.
4. After GitHub gives you the temporary Pages URL, add templesofsound.life under Settings > Pages > Custom domain.
5. Configure the domain DNS using the records GitHub shows for your custom domain.

Google Calendar:
On events.html, replace the placeholder calendar box with your public Google Calendar iframe once you have the embed code.
