# Temples of Sound website

A concise, mobile-friendly static homepage ready for GitHub Pages.

## Upload to GitHub

1. Upload `index.html` and `styles.css` to the main level of the repository, replacing earlier versions.
3. Open the repository's **Settings**, then **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

GitHub will show the public website address after it publishes.

## Edit later

- Page wording is in `index.html`.
- Colors, fonts, spacing, and layout are in `styles.css`.
- The gathering buttons currently open `@temples.of.sound` on Instagram. Replace those links if you have a dedicated event calendar.
- The decorative lotus is CSS, since the original logo image was not part of these source files. Add the original art and real gathering photographs when they are available.
- For `templesofsound.life`, configure the custom domain and DNS in GitHub Pages, then enable **Enforce HTTPS**. This code update alone cannot fix the current HTTP security warning.
